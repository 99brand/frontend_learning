# frontend_learning

从零开始的前端学习笔记仓库。目前是**原生 HTML / CSS / JavaScript**，不引入任何框架和依赖。

## 怎么运行

不需要安装任何东西，也不需要起服务器。

**方式一（最简单）**：双击 `index.html`，浏览器直接打开。

**方式二（推荐）**：用 VS Code 打开文件夹，安装 **Live Server** 插件，  
右键 `index.html` → "Open with Live Server"。  
好处是保存文件后浏览器会自动刷新，改代码时不用手动按 F5。

## 文件都是干什么的

| 文件           | 职责                   | 类比    |
| ------------ | -------------------- | ----- |
| `index.html` | 页面**结构和内容**（有什么元素）   | 房子的骨架 |
| `styles.css` | 页面**长什么样**（颜色、间距、大小） | 房子的装修 |
| `main.js`    | 页面**怎么动**（响应点击、更新数据） | 房子的水电 |

这三层分开放，是前端最基础也是最重要的一个习惯。

## 当前页面：个人任务管理 Dashboard

现在的 `index.html` 是一个任务看板，**纯静态**（数据在 HTML 里写死，没有交互）。  
页面从上到下分成四块：

| 区块                  | 用到的标签           | 负责排版的 CSS |
| ------------------- | --------------- | --------- |
| 页面头部（标题 + Add Task） | `<header>`      | Flexbox   |
| 三张统计卡片              | `<div>` ×3      | CSS Grid  |
| 今日任务列表              | `<ul>` / `<li>` | Flexbox   |
| 计数器（旧练习）            | `<section>`     | ——        |

## 这个小项目涉及的前端概念

1. **DOM** — 浏览器把 HTML 解析成的一棵树，JS 通过它找到并操作页面元素。
2. **`document.getElementById()`** — 按 id 在 DOM 树里查元素的标准方法。
3. **事件监听 `addEventListener`** — "当某某事情发生时，执行这个函数"。浏览器是事件驱动的。
4. **状态 + 渲染** — `count` 是数据（唯一事实来源），`render()` 负责把它画到界面上。  
   改数据时只在JS里改变量，然后重新渲染，而不是手动去拼 DOM 字符串。
5. **`<script>` 放 `</body>` 前** — 保证脚本执行时 DOM 已经存在。
6. **CSS 盒模型 `box-sizing: border-box`** — 让宽高计算符合直觉。
7. **语义化标签** — `<header>`、`<section>`、`<ul>`、`<li>`。显示效果和 `<div>` 一样，  
   但标签名自带含义，别人（和搜索引擎、读屏软件）一眼就知道这块是干什么用的。
8. **Flexbox** — 一维布局。让一排元素横着排，常用三个属性：
   - `justify-content: space-between` — 把剩余空间塞到元素中间，实现"一个靠左、一个靠右"
   - `align-items: center` — 让这一排元素垂直居中对齐
   - `flex: 1` — 某个元素独占剩余宽度，会把兄弟元素推到两边
9. **CSS Grid** — 二维布局。`grid-template-columns: repeat(3, 1fr)` 就是"三等分"，  
   做卡片宫格比 Flexbox 省事得多。
10. **追加而不是覆盖** — 这次新样式全部写在 `styles.css` 末尾，没有动计数器那段。  
    旧代码能跑就别碰，是减少 bug 的最有效手段。
